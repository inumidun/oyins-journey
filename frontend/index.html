🚀 Oyin's Journey

A real, deployed cloud system that is your CV — not a PDF, not a portfolio site — but a self-documenting, queryable, versioned cloud architecture that proves your skills by existing.

📡 API Endpoints

GET /skills

Query skills and technologies

GET /projects

List projects and experience

GET /certifications

List certifications and credentials

GET /architecture/decisions

Architecture Decision Records (ADRs)

GET /version

Current CV version and release history

🏗️ Architecture

  • API Gateway + Lambda - Serverless API endpoints
  • DynamoDB - Skills, projects, ADRs storage
  • S3 + CloudFront - Frontend hosting
  • CloudWatch - Observability
  • GitHub Actions - CI/CD
